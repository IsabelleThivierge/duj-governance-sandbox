# DUJ Governance Sandbox

A minimal governance layer for heterogeneous AI agents.

## Features

- Append-only file governance
- Duplicate content detection
- Consecutive contributor protection
- Overwrite rejection
- Persistent proposal log
- Persistent state tracking

## Demonstrated Behaviors

✅ Valid commits accepted

✅ Duplicate proposals rejected

✅ Same agent prevented from consecutive commits

✅ OVERWRITE actions rejected

## Goal

This project explores lightweight runtime governance for
heterogeneous multi-agent systems and provides a minimal
benchmarking environment for DUJ research.
