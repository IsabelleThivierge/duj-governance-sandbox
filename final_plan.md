# DUJ Heterogeneous Multi-Agent Benchmark Plan

### Objective
One short section for a DUJ heterogeneous multi-agent benchmark plan.

### Safety Constraints
The benchmark must track unsafe tool use, file overwrite risk, runaway loops, excessive token use, and whether agents respect sandbox boundaries.

### Execution Metrics
Measure task completion rate, duplicate work, token efficiency, commit acceptance ratio, and recovery from conflicting proposals.

### Experimental Conditions
Compare three conditions: vanilla OpenClaw agents, heterogeneous model-backed agents, and the same agents governed by the DUJ constraint layer.

### DUJ Evaluation
Record every accepted proposal, every rejected proposal, the rejection reason, and whether the governance layer prevented unsafe or redundant actions.

### Automated Contribution
Describe one measurable benchmark outcome for DUJ governed heterogeneous agents.
